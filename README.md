# HTE UV-Vis 快速筛选工具（HH-AgCumulene-HTE）

一个基于 Tkinter 的桌面小工具，用于把酶标仪（plate reader）导出的 UV-Vis 光谱数据快速转换成 **96 孔板的产率热图**。

它读取 Excel 中的全波长光谱，对 390–560 nm 做积分吸光度计算，用标准样线性外推产率，并用**余弦相似度**校验谱型是否与目标产物一致，最后把两个维度评分以颜色形式直接渲染在 8×12 孔板上，支持导出 CSV 和散点图。

> 当前主版本：[`HTE_UVVis_GUI_v3_baseline.py`](./HTE_UVVis_GUI_v3_baseline.py)

## 功能特性

- **一键读板**：直接读入酶标仪 Excel 的 `Well results` 工作表，自动识别波长表头，解析 A1–H12 全部孔位。
- **可选基线校正**：取指定波长区间（默认 700–900 nm）的平均吸光度作为基线，从整条光谱中扣除；基线区间内无有效数据会明确报错。
- **产率预测**：对 390–560 nm 做梯形积分，经标准曲线换算为 0–100% 产率。
- **谱型校验**：按预测产率在 10 条标准谱之间插值出参考谱，与实测谱做余弦相似度，识别"强度够但谱型不对"的假阳性。
- **二维评分配色**：吸光度分 × 相似度分四角双线性混合，白 / 黄 / 紫 / 红一眼区分强弱与真假。
- **结果导出**：CSV（含基线信息，UTF-8 BOM，Excel 直接打开不乱码）+ 300 dpi 散点图。
- **单文件零配置**：标准谱以 base64 + zlib 压缩内嵌，无需外部数据文件即可运行。

## 使用方法

1. 点击 **上传Excel**，选择酶标仪导出的 `.xlsx` / `.xlsm` 文件。
2. （可选）勾选 **基线校正**，填写基线波长范围（默认 `700` – `900` nm）。勾选后标准曲线与标准参考谱会用**同一区间**重新校正。
3. 点击 **预测**，96 孔板视图立即填色并显示数值。
4. 点击 **导出CSV** 保存数值结果，或 **导出散点图** 保存可视化图。

执行后会提示本次分析的有效孔数以及所用的基线区间。

## 输入文件要求

脚本对 Excel 的读取约定如下（见 `parse_spectra`）：

- 工作簿中必须存在名为 **`Well results`** 的工作表（匹配时忽略大小写和首尾空格）。
- 表头行：第一列为文本 **`Well`**，且同一行需同时出现数值 **390** 和 **560**（用于定位并确认波长行）。找不到会报错 `无法找到包含波长的 'Well' 表头。`
- 数据行：第一列为孔位编号，需匹配 `A1`–`H12` 格式；其余列按表头波长顺序给出吸光度。
- 非数值单元格按缺失（NaN）处理；行尾缺失值自动补 NaN；波长/吸光度有效数据点少于 2 个的孔会被跳过。
- 文件以 `data_only=True` 读取，因此 **Excel 需要保存过公式计算结果**，否则公式单元格读不到数值。

## 算法说明

所有计算均为独立纯函数，便于复用和测试。

**1. 基线校正**（`baseline_correct`，可选）

取 `[lo, hi]` 区间内所有有效点的平均吸光度作为基线，从整条光谱中扣除。若区间内有效点少于 2 个则报错。

**2. 标准曲线**（`get_standard_model`）

对 10 条内嵌标准谱（产率 10%、20%…100%，每步 10%）分别做基线校正 → 计算 390–560 nm 梯形积分 → 用最小二乘拟合：

```
yield = slope × total_absorption + intercept
```

**3. 单孔分析**（`analyze_spectrum`）

- 积分吸光度：`total = ∫ y dλ`（390–560 nm，梯形法，AU·nm）
- 预测产率：`yield = clip(slope × total + intercept, 0, 100)`
- 相似度：把实测谱线性插值到标准波长网格上，与"按预测产率插值得到的参考谱"求余弦相似度；若实测波长范围未能覆盖 390–560 nm，则记为 `NaN`

**4. 评分归一化**

| 分数 | 公式 | 说明 |
| --- | --- | --- |
| 吸光度分 | `clip(total / 100, 0, 1)` | 0 AU·nm 及以下 0 分，≥ 100 AU·nm 满分 |
| 相似度分 | `clip((27.5° − θ) / 27.5°, 0, 1)`，`θ = arccos(clip(sim, −1, 1))` | 夹角 0° 满分，≥ 27.5° 0 分；`NaN` 记 0 分 |

用夹角而非相似度原值，是为了把非线性的余弦关系转成可直接加权的线性分数。

## 界面与配色

每个孔显示三行：

```
A=123.4            ← 基线校正后 390–560 nm 积分总吸收（AU·nm）
Y=68.2%            ← 预测产率
S=0.993            ← 与对应预测产率标准谱的余弦相似度（数据不足时显示 NA）
```

背景色由两个分数做**四角双线性混合**，权重为 `w_abs = 吸光度分`、`w_sim = 相似度分`：

| 情形 | 颜色 |
| --- | --- |
| 双 0 分 | 白色 |
| 吸光度满分 | 亮黄 |
| 相似度满分 | 紫罗兰 |
| 双满分 | 大红 |

配色含义：**红**＝量足且谱型正确（优先候选）；**黄**＝信号强但谱型偏差（可能是副产物或干扰）；**紫**＝谱型像但信号弱；**白**＝无有效信号。

## 输出文件

### CSV

按孔位 A1→H12 顺序输出（仅含分析成功的孔），UTF-8 BOM 编码：

| 列名 | 含义 |
| --- | --- |
| `Well` | 孔位编号 |
| `Baseline corrected total absorption 390-560 nm` | 积分总吸收（AU·nm，6 位小数） |
| `Predicted yield (%)` | 预测产率 |
| `Spectral similarity` | 余弦相似度 |
| `Baseline absorbance` | 扣除的基线吸光度 |
| `Baseline correction` | 是否启用基线校正（Yes/No） |
| `Baseline range (nm)` | 基线区间（未启用时为空） |

### 散点图

- 横轴：390–560 nm 积分吸光度（AU·nm）
- 纵轴：谱型余弦相似度
- 每个点标注孔位编号，300 dpi PNG

用于同时观察"产量—纯度"分布，挑出高吸光度且高相似度的孔。

## 参数调整

脚本顶部的常量集中了所有可调参数（第 7–15 行附近）：

```python
ROWS = list("ABCDEFGH"); COLS = list(range(1, 13))
STANDARD_YIELDS = np.arange(10, 101, 10, dtype=float)

ABSORBANCE_FULL_SCORE = 100.0   # 积分吸光度达到该值即为吸光度满分
SIMILARITY_ZERO_ANGLE = 27.5    # 夹角达到该度数即为相似度 0 分

COLOR_WHITE  = (255, 255, 255)
COLOR_YELLOW = (255, 255, 0)
COLOR_VIOLET = (238, 130, 238)
COLOR_RED    = (255, 0, 0)
```

- 更换反应体系 / 显色物种：调整 `ABSORBANCE_FULL_SCORE`、`SIMILARITY_ZERO_ANGLE` 与标准谱数据。
- 更换板型（如 384 孔）：修改 `ROWS` / `COLS` 与孔位正则即可。
- 积分窗口目前硬编码为 390–560 nm（`analyze_spectrum` / `get_standard_model` 中的 `target` 掩码）。

## 更新与重建标准谱

标准谱以 `zlib` 压缩 + `base64` 编码后内嵌在 `_STD_BLOB` 中，解码后 reshape 为 `(n, 11)`：**第 0 列为波长，后 10 列为 10 个产率梯度（10%–100%）的标准谱**。

用新数据重新生成：

```python
import base64, zlib
import numpy as np

# wavelengths: (n,) 波长
# spectra:     (n, 10) 每一列对应 10%、20% … 100%
arr = np.column_stack([wavelengths, spectra]).astype("<f8")
blob = base64.b64encode(zlib.compress(arr.tobytes(), 9)).decode()
print(blob)
```

把输出字符串替换脚本中的 `_STD_BLOB` 即可。

## 常见问题

**Q：提示"未找到 'Well results' 工作表。"**
A：确认 Excel 中存在该名称的工作表（脚本忽略大小写与首尾空格）。

**Q：提示"无法找到包含波长的 'Well' 表头。"**
A：表头行第一列必须是 `Well`，且该行需包含数值 390 和 560。请检查导出的表头格式。

**Q：某孔相似度显示 `NA`。**
A：实测波长范围未完整覆盖 390–560 nm（通常是被扣掉或缺失了端点），该孔相似度分按 0 计。

**Q：所有结果偏低或偏高。**
A：检查是否需要开启基线校正，并确认基线区间内确实只有背景信号（默认 700–900 nm，适合该体系）。必要时重新拟合标准谱。

**Q：Excel 读出来全是空值。**
A：光谱出自公式单元格时，请先在 Excel 中打开并保存一次，让公式结果被写入文件。
